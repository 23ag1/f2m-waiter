# Food2Mood — ИИ-рассылки (demo)

Standalone-демо модуля **персонализированных рассылок** из проекта Food2Mood.
Админ описывает рассылку текстом → LLM извлекает сегмент → фильтруются профили →
LLM генерирует персональное сообщение каждому получателю.

## Что внутри

- **Backend** (FastAPI + psycopg2): извлечение фильтров, фильтрация пользователей в PostgreSQL,
  генерация сообщений через DeepSeek, логирование истории, отправка в Telegram.
- **Frontend** (vanilla JS SPA): сегментирование, превью с потоковой генерацией,
  калькулятор стоимости (SMS / Email), редактируемые сообщения, история.
- **Postgres 16** с автоматическим seed'ом (25 тестовых профилей + история заказов).

## Быстрый старт

Требуется установленный Docker + Docker Compose.

```bash
git clone https://github.com/Dracual12/food2mood-broadcast-demo.git
cd food2mood-broadcast-demo
docker compose up --build
```

Подождать ~30 секунд, пока поднимется Postgres и зальётся seed. Затем:

- **UI:** <http://localhost:8080>
- **API:** <http://localhost:8000>
- **API docs (Swagger):** <http://localhost:8000/docs>

## Mock-режим (по умолчанию)

В демо включён `MOCK_LLM=true` — реальный DeepSeek **не вызывается**, ответы генерируются локально.
Что это даёт:

- Превью отрабатывает за 3-5 секунд (вместо 30-60 с реальным LLM)
- Не нужен интернет / API-ключ
- Поведение полностью предсказуемо

**Гибридный режим:**
- Запрос про **«Том Ям»** — детальный сценарий: фильтр блокирует креветки/морепродукты/чили/лемонграсс/кокосовое молоко, категория «Супы», персональные сообщения зависят от стиля питания и предпочтений профиля.
- **Любой другой запрос** — универсальный шаблонный ответ.

Чтобы включить реальный DeepSeek — выставьте `MOCK_LLM=false` и пропишите валидный `DEEPSEEK_API_KEY`.

## Как тыкать (сценарий для продакта)

1. Открыть <http://localhost:8080>.
2. В карточке **«Новая рассылка»** задать сегмент:
   - Пол / возраст / последнее посещение — опционально
   - Тип рассылки (промпт): `Стандартный`, `Кликбейт`, `Реактивация` и т.д.
3. **Главный демо-запрос:** `Новый суп Том Ям уже в меню`. Также работают:
   - `Новая паста Карбонара уже в меню` (универсальный fallback)
   - `Вернитесь к нам — у нас новые блюда`
   - `Скидка 20% на всё меню в пятницу`
4. Нажать **«Превью»** — извлекутся фильтры, найдутся подходящие из 45 профилей,
   сгенерируются персональные сообщения (поток, получатели появляются по одному).
5. В таблице **«Получатели»** можно:
   - Редактировать сообщение вручную
   - Удалять получателей (крестик слева) — сумма в **калькуляторе стоимости** пересчитывается
   - Переключать канал **SMS (6 ₽)** / **Email (0.18 ₽)** — сумма меняется
6. Нажать **«Отправить всем»** — уйдёт реально в Telegram только если задан `BOT_TOKEN` в `.env`.
   Иначе — 500, это нормально для демо-превью.

## Эндпоинты

| Метод | Путь                                | Назначение                                |
| ----- | ----------------------------------- | ----------------------------------------- |
| GET   | `/api/v1/broadcast/templates`       | Список шаблонов промптов                  |
| POST  | `/api/v1/broadcast/preview/stream`  | NDJSON-стрим: фильтры + получатели        |
| POST  | `/api/v1/broadcast/preview`         | То же, но batch (для интеграций)          |
| POST  | `/api/v1/broadcast/send`            | Отправка через Telegram Bot API           |
| GET   | `/api/v1/broadcast/history`         | История рассылок                          |
| GET   | `/health`                           | Health-check                              |
