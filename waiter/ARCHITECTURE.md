## Флоу работы официанта

```
Официант открывает приложение
        │
        ▼
Авторизация по PIN
        │
        ▼
Главная: активные столы
        │
        ├─── Новый заказ ──▶ Выбор стола (iiko) ──▶ Кол-во гостей ──▶
        │                                                              │
        │    ◀─────────────────────── Создание сессии стола ──────────┘
        │                    
        ├─── Сканировать QR гостя ──▶ Получить client_id
        │
        ▼
Корзина гостя / Мультигость
        │
        ├─── Добавить блюдо ──▶ Меню (фильтр по ресторану)
        │                        └──▶ Модификаторы
        │                        └──▶ Комментарий к блюду
        │
        ├─── Рекомендации ──▶ Движок (3 уровня, см. выше)
        │
        └─── Отправить в iiko ──▶ Заказ создан
                └─── Пречек ──▶ Печать счёта
```

## Идентификация гостя

```
QR-код гостя
    │
    ├── Из нашего Wallet (Apple/Android) ──▶ user_id + phone
    │
    └── Из внешней программы лояльности ──▶ phone ──▶ lookup user_id
                                                       в таблице profile
```

## Портируемость ЦВП

Вкусовой профиль гостя (`profile.user_temp_sort`) привязан к `user_id`
и может использоваться в **любом ресторане** сети — данные о вкусах
не зависят от конкретного заведения.

CRM-данные (`orders_history`) привязаны к `restaurant_name` и
используются только в контексте конкретного ресторана.
